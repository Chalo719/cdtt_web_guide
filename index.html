📄 Основы вёрстки веб-страниц и разработки сайтов

В современном мире веб-технологии пронизывают все сферы жизни: от образования и медицины до бизнеса и развлечений. Каждая компания, организация или частный специалист стремится иметь собственный сайт или веб-приложение.

HTML и CSS — это основа любого сайта, а JavaScript добавляет интерактивность и «жизнь» веб-страницам.

Работа над собственными сайтами (лендинг, портфолио, интернет-магазин) помогает развить творческие способности, дизайнерское мышление и навыки решения практических задач.

✨ Практическое задание

Задача: собрать свою первую тестовую страницу из фрагментов кода из презентации.

1. Установите VS Code.

2. Установите расширение LiveServer.

3. Создайте файл index.html и запишите в нём HTML-код из презентации.

4. Добавьте CSS-стили из презентации в тег <style>.

5. Добавьте JavaScript-код из презентации в тег <script>.

6. Запустите страницу через LiveServer.

7. Откройте DevTools (F12) и изучите вкладки Elements, Console и Network.

✨ Практическое задание

Задача: создать страницу-визитку с использованием заголовков разных уровней и форматированного текста.

Требования к странице:

  1. Создайте файл index.html с правильной структурой документа.
  2. Добавьте заголовок первого уровня (<h1>) с вашим именем или названием визитки.
  3. Используйте заголовки второго и третьего уровней (<h2>, <h3>) для разделов: «Обо мне», «Мои навыки», «Контакты».
  4. Напишите текст в параграфах (<p>) с информацией о себе.
  5. Примените теги форматирования: <strong> (жирный), <em> (курсив), <br> (перенос строки).
  6. Добавьте горизонтальную линию <hr> между разделами.
  7. Сохраните файл и откройте в браузере.

✨ Практическое задание

Задача: создать навигационное меню с переходами между несколькими HTML-страницами.

Требования к проекту:

  1. Создайте папку site с тремя HTML-файлами:
    • index.html — главная страница
    • about.html — страница «О себе»
    • contact.html — страница «Контакты»
  2. На каждой странице сделайте навигационное меню для перехода на другие страницы.
  3. Добавьте якорные ссылки внутри главной страницы для навигации по разделам (например, «Образование», «Хобби», «Навыки»).
  4. Оформите каждую страницу с заголовками и параграфами (используйте навыки из темы 1.1).
  5. Проверьте, что все относительные пути работают корректно при открытии index.html в браузере.

Дополнительное задание:

  • Добавьте на главную страницу ссылку на внешний сайт (например, на Доку), которая открывается в новой вкладке.
  • Сделайте ссылку на скачивание какого-нибудь файла (можно просто текстового).

✨ Практическое задание

Задача: создать галерею изображений с использованием разных форматов и правильным альтернативным текстом.

Требования к странице:

  1. Создайте HTML-страницу gallery.html с правильной структурой.
  2. Добавьте заголовок <h1> «Моя галерея изображений».
  3. Разместите на странице 4 изображения:
    • Фотография в формате JPG.
    • Изображение с прозрачностью в формате PNG.
    • Иконка или логотип в формате SVG.
    • Изображение в современном формате WebP.
  4. Для каждой картинки:
    • Задайте осмысленный атрибут alt.
    • Укажите ширину и высоту через атрибуты width и height.
  5. Под каждым изображением добавьте подпись — описание формата и его особенностей (например: «JPEG — хорош для фотографий, поддерживает 16 млн цветов»).

Дополнительное задание:

  • Оберните картинки в ссылки так, чтобы при клике открывалась полноразмерная версия.
  • Добавьте атрибут loading="lazy" к изображениям, чтобы они загружались только при прокрутке.
